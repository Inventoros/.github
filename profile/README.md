<h1 align="center">Inventoros</h1>

<p align="center"><strong>Inventory management for the rest of us.</strong></p>

Inventoros is a free, open-source inventory and warehouse management system. It tracks products, stock across warehouses and locations, purchase orders, customer orders, returns and stock audits, and it runs on your own server, from a VPS or Docker to plain cPanel hosting. It is built with Laravel, Inertia and Vue, and licensed under the AGPL v3.

### Contributing

Bug reports, fixes, translations and plugins are all welcome. Start with the [contributing guide](https://github.com/Inventoros/Inventoros/blob/main/CONTRIBUTING.md), open an [issue](https://github.com/Inventoros/Inventoros/issues) to report a problem or suggest a change, or read the [plugin development guide](https://github.com/Inventoros/Inventoros/blob/main/docs/PLUGIN_DEVELOPMENT.md) to build your own extension. Security issues go through the [security policy](https://github.com/Inventoros/Inventoros/blob/main/SECURITY.md), not public issues.
